Histórico do Projeto FIIs (Pré-Databricks)

O projeto FIIs nasceu com o objetivo de construir um pipeline completo de dados e Machine Learning capaz de identificar oportunidades de investimento em Fundos de Investimento Imobiliário (FIIs) logísticos e prever quais ativos possuem maior probabilidade de apresentar retorno total superior ao IFIX. Desde o início, a estratégia definida foi utilizar o IFIX como benchmark oficial do projeto e desenvolver modelos capazes de capturar padrões históricos de desempenho para superar esse índice de referência.

A primeira etapa consistiu na definição do escopo do projeto e dos ativos que fariam parte da análise inicial. Foram selecionados cinco FIIs logísticos amplamente negociados no mercado brasileiro: HGLG11, BTLG11, XPLG11, LVBI11 e VILG11. A escolha desses fundos foi motivada pela representatividade no segmento logístico, disponibilidade de histórico de mercado e relevância dentro do universo de FIIs acompanhados por investidores.

Após a definição dos ativos, foi criada a estrutura base do projeto em ambiente local utilizando Python. Foi configurado um ambiente virtual (.venv) para isolamento de dependências e organização do desenvolvimento. A estrutura inicial do diretório foi organizada de forma a separar responsabilidades entre ingestão de dados, notebooks analíticos e futuras aplicações de visualização. A arquitetura inicial ficou composta pelas pastas ingestion, notebooks e dashboard, permitindo uma evolução organizada do projeto.

Em seguida foi criado o repositório oficial do projeto no GitHub, denominado projeto-fiis. Durante essa etapa foram adicionados os arquivos fundamentais para governança e colaboração, incluindo README.md, .gitignore e requirements.txt. O repositório passou a servir como fonte única de verdade do projeto, garantindo versionamento completo do código e integração futura com outras plataformas.

Com a infraestrutura básica pronta, iniciou-se a construção dos pipelines de ingestão de dados. O primeiro script desenvolvido foi o fetch_data.py, responsável por coletar o histórico de cotações dos FIIs selecionados utilizando a biblioteca yfinance. Durante o desenvolvimento foi identificado um problema relacionado ao formato MultiIndex retornado pela API, que exigiu uma correção específica para simplificação do schema antes da exportação. Após os ajustes, o script passou a coletar corretamente os dados históricos dos cinco FIIs desde 2010 e armazená-los em arquivos CSV dentro de ingestion/data.

Na sequência foi desenvolvido o script fetch_dividends.py, responsável pela captura do histórico de dividendos dos mesmos FIIs. O objetivo era registrar todos os eventos de distribuição de rendimentos relevantes para cálculo de retorno total. O script gerava arquivos CSV independentes para cada ativo, permitindo posteriormente a consolidação e análise dos fluxos de dividendos.

Paralelamente ao trabalho com os FIIs, foi construída a base histórica do IFIX. Inicialmente os dados foram organizados em arquivos anuais separados, abrangendo o período de 2011 até 2026. Posteriormente esses arquivos foram consolidados em uma única base denominada IFIX_completo.csv, formando o benchmark oficial utilizado ao longo de todo o projeto.

Uma das decisões mais importantes dessa fase ocorreu durante a integração entre GitHub e Databricks. Inicialmente a pasta ingestion/data estava sendo ignorada pelo Git através de uma regra presente no .gitignore. Isso impedia que os arquivos de dados chegassem ao repositório remoto. Após análise da arquitetura desejada, foi decidido remover essa regra e passar a versionar os arquivos CSV diretamente no GitHub. Essa mudança eliminou a necessidade de uploads manuais para o Databricks e permitiu que todo o conteúdo da pasta de dados fosse sincronizado automaticamente através dos Repos.

Com os scripts de ingestão finalizados e os dados versionados corretamente, o projeto passou a possuir uma base consolidada contendo o histórico de preços dos cinco FIIs selecionados, o histórico de dividendos dos mesmos ativos e uma série histórica completa do IFIX. Nessa fase também foi validada a presença dos arquivos gerados no repositório, garantindo que toda a cadeia de coleta e armazenamento estivesse funcionando corretamente.

Como preparação para a migração para o Databricks, foi definida a estratégia de modelagem que seria utilizada posteriormente. A decisão tomada foi utilizar uma abordagem de validação walk-forward com janela expansiva, buscando prever retornos futuros e comparar sistematicamente os resultados com o desempenho do IFIX. Essa definição foi fundamental para orientar o desenho das futuras tabelas Bronze, Silver e Gold e para estabelecer a lógica de construção do dataset de Machine Learning.

Ao final da fase de desenvolvimento local, o projeto já contava com ambiente Python estruturado, repositório GitHub configurado e sincronizado, pipelines de ingestão para preços, dividendos e IFIX totalmente funcionais, armazenamento dos dados em arquivos CSV padronizados e uma estratégia quantitativa claramente definida para as próximas etapas. Essa base serviu como ponto de partida para a construção da arquitetura Medallion no Databricks e para toda a evolução posterior do projeto.



Fontes de Dados Utilizadas

Durante a fase de ingestão foram utilizadas diferentes fontes para compor a base histórica do projeto.

Inicialmente, as cotações dos FIIs foram coletadas utilizando a biblioteca yfinance, que consome dados do Yahoo Finance. Entretanto, durante as validações foi identificado que os históricos disponibilizados para alguns FIIs apresentavam lacunas e inconsistências em determinados períodos, comprometendo a confiabilidade da série temporal para fins de modelagem.

Diante desse problema, a estratégia foi revisada e passou-se a utilizar os dados disponibilizados pelo Status Invest como fonte principal para os FIIs. Essa decisão foi tomada para garantir maior completude do histórico de preços e dividendos dos ativos analisados. A partir daí, os dados de HGLG11, BTLG11, XPLG11, LVBI11 e VILG11 passaram a ser obtidos e consolidados utilizando informações do Status Invest, incluindo cotações históricas e eventos de distribuição de rendimentos.

Para o benchmark do projeto, o histórico do IFIX foi obtido através do Yahoo Finance, utilizando a biblioteca yfinance. Diferentemente dos FIIs individuais, a série do IFIX apresentou qualidade e cobertura adequadas para o período analisado, abrangendo aproximadamente de 2011 até 2026 após a consolidação dos arquivos.

Ao final da fase de ingestão, o projeto passou a contar com três grandes conjuntos de dados:

Histórico de cotações dos FIIs, obtido a partir do Status Invest.
Histórico de dividendos dos FIIs, também obtido a partir do Status Invest.
Histórico do IFIX, obtido através do Yahoo Finance.

Todos os dados foram armazenados em arquivos CSV dentro da pasta ingestion/data e versionados no GitHub para permitir sincronização direta com o Databricks Repos, eliminando a necessidade de uploads manuais e garantindo reprodutibilidade do ambiente.
